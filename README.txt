Portfolio of Ram Laxman Shastry Jagarlapudi
Layout based on the iPortfolio template by BootstrapMade (https://bootstrapmade.com/iportfolio-bootstrap-portfolio-websites-template/)

Open index.html in a browser (internet needed for fonts, icons and Bootstrap, which load from a CDN).

Folders
  index.html            main page
  assets/css/style.css  all custom styling
  assets/js/main.js     navigation, typing effect, animations, contact form
  assets/img/           profile photo (also used as the hero background)
  assets/resume/        resume PDF (download buttons)
